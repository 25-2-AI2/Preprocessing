# Aspect Scoring Guideline

---

## 1. Scoring Scale 정의 (-2 ~ +2)

각 Aspect는 다음 기준을 통해 -2에서 +2까지의 점수를 가진다.

| 점수 | 의미 | 설명 |
| --- | --- | --- |
| **+2** | 매우 긍정 (Very Positive) | 강한 칭찬, 최고 수준, 반복적 찬사, 강한 만족 |
| **+1** | 긍정 (Positive) | 대체로 좋음, 전반적으로 만족 |
| **0** | 중립 / 언급 없음 (Neutral) | 해당 Aspect 언급 없음 / 평가 모호 |
| **-1** | 부정 (Negative) | 실망, 다소 부정적, 문제 있으나 치명적 아님 |
| **-2** | 매우 부정 (Very Negative) | 강한 비난, 최악, 위험 요소, 심각한 불만 |

---

## 2. Aspect 정의 및 점수 기준

아래 7개 Aspect는 맛집 리뷰 도메인에서 가장 핵심적인 품질 요소이며,

각각 -2 ~ +2로 점수를 부여한다.

---

### 2.1 FOOD (맛·음식·음료) → `food_score`

음식뿐 아니라 음료(맥주, 칵테일, 커피 등)까지 포함한

전체 섭취 품질을 평가한다.

### +2 (매우 긍정)

- “best I’ve ever had”, “amazing”, “incredible”, “perfect”
- “♡♡♡”, “인생 맛집”, “완벽”
- “매주 먹으러 간다”, “여기 때문에 여행 다시 오고 싶다”

### +1 (긍정)

- “good”, “tasty”, “맛있다”, “괜찮다”
- 좋은 편이지만 아주 빼어나지는 않은 경우

### 0 (중립 / 언급 없음)

- 음식/음료 평가가 아예 없음
- 애매한 표현 (“okay”, “fine”)
- “음식은 괜찮았으나…”처럼 뒤 내용을 위한 도입부

### 1 (부정)

- “not good”, “a bit salty”, “underwhelming”
- 맛/양/온도 문제 있으나 치명적 수준은 아님

### 2 (매우 부정)

- “worst”, “disgusting”, “inedible”, “토할 것 같았다”
- 심각한 품질 문제, 다시는 안 올 것 같다는 표현

---

### 2.2 SERVICE (친절·응대·속도) → `service_score`

고객 응대 태도, 친절도, 요청 처리, 음식 조리/서빙 속도(테이블 내 서비스)까지 포함한다.

| 점수 | 확정 기준 |
| --- | --- |
| **+2** | 감동적인 응대 **또는** 친절·응대·속도 전반에 대한 최상급 극찬. |
| **+1** | 친절함, 도움이 됨, 기본 이상으로 괜찮은 응대. 또는 “서비스가 빨랐다”는 긍정적 언급. |
| **0** | 서비스에 대한 언급 없음, 혹은 중립적인 기술(“서빙 받음” 수준). |
| **-1** | 무례함, 다소 느린 응대, 요청을 여러 번 해야 처리해주는 등 **불편하지만 치명적이지 않은 수준**. |
| **-2** | 폭언, 폭행, 고의적 무시, 계산 실수 방치, 고객 안전 위협 등 **심각한 갈등·스트레스 유발 서비스**. (인종차별은 별도 `racism_flag`에서 처리) |

---

### 2.3 AMBIENCE (분위기·소음·인테리어) → `ambience_score`

매장 느낌, 조명, 소음, 분위기, 인테리어, 안전감 등을 포함.

### +2

- “cozy”, “romantic”, “beautiful space”
- “분위기가 너무 좋았다”, “데이트하기 딱 좋다”

### +1

- “nice vibe”, “pleasant”, “조용하고 좋았다”

### 0

- 분위기·소음·인테리어에 대한 언급 없음

### 1

- “noisy”, “too crowded”, “어수선함”, “시끄러웠다” 정도의 일반적 불편

### 2

- “unsafe vibe”, “people fighting”, “시끄러워서 대화 불가”
- 폭력/위협적 분위기, 계속된 싸움, 매우 불쾌한 분위기

---

### 2.4 PRICE (가격·가성비) → `price_score`

가격 수용성, 저렴함/비쌈, 가치 대비 만족도.

### +2

- “great value”, “가성비 최고”, “affordable and amazing”

### +1

- 가격 대비 대체로 만족, “비싸지 않은 편”, “가격도 괜찮았다”

### 0

- 가격 관련 언급 없음
- 가격 언급이 있지만 명확히 긍/부정이 아닌 경우

### 1

- “a bit expensive”, “가격이 다소 높음”
- “조금 비싸지만 이해 가능한 수준”

### 2

- “overpriced”, “rip-off”, “돈 아까움”
- 가격에 대한 강한 분노/배신감 표현

> 참고: “cash only” 같은 결제 제약은 cash_only_flag에서 별도 처리하되,
> 
> 
> 여행자에게 불리한 경우 `price_score`를 -1로 둘 수 있음.
> 

---

### 2.5 HYGIENE (위생) → `hygiene_score`

청결, 음식 위생, 바닥/테이블/화장실 상태 등.

### +2

- “spotless”, “very clean”, “너무 깨끗했다”

### +1

- “clean enough”, “깔끔했다”
- 대체로 청결, 특별한 문제 없음

### 0

- 위생 관련 언급 없음

### 1 (부정)

- “dirty table”, “좀 지저분했다”
- 끈적이는 테이블, 정리 안 된 상태, 화장실 청결 약간 문제
- 직원의 경미한 위생 규칙 미준수 (예: 장갑 안 끼고 만지는 정도)

### 2 (매우 부정)

- 건강/안전 위협 수준:
    - 음식 내 이물질(머리카락 제외 심각한 것들), 바퀴벌레, 쥐, 곰팡이
    - 재료 재사용 목격, 유통기한 지난 재료 사용 주장
    - “여기 다녀온 뒤 식중독 걸렸다” 등 강한 위생 문제 호소

---

### 2.6 WAITING (웨이팅/대기 시간) → `waiting_score`

**식당 입장 / 자리 배정까지의 대기 시간**을 평가한다.

(음식이 늦게 나오는 것은 상황에 따라 service에 들어갈 수도 있지만,

“줄 서서 기다린 시간”은 waiting에 집중해서 표기)

| 점수 | 확정 기준 |
| --- | --- |
| **+2** | “대기 없음”, “바로 들어갔다”, “기대보다 훨씬 빨리 입장했다”. |
| **+1** | 약간의 웨이팅이 있었으나 불만을 유발하지 않는 수준 (예: “5~10분 정도 기다렸지만 괜찮았다”). |
| **0** | 웨이팅/줄 관련 언급 없음. |
| **-1** | “꽤 오래 기다렸다”, “줄이 길다” 등 **불편한 대기**가 있었으나, 구체적 시간이 1시간 미만. |
| **-2** | “1시간 이상 기다렸다”, “예약했는데도 30분 이상 더 기다렸다”, “대기 시간 때문에 다시 오고 싶지 않다” 등 **극도로 긴 대기**. |

---

### 2.7 ACCESSIBILITY (위치·이동·주차) → `accessibility_score`

위치 편리성, 대중교통·도보 접근성, 주차 가능 여부.

### +2

- “easy parking”, “plenty of parking”, “perfect location”
- “역에서 바로 앞”, “주차가 정말 편했다”

### +1

- 무난한 접근성, “찾기 쉬운 편”, “주차 자리가 있긴 했다”

### 0

- 위치/주차 관련 언급 없음

### 1

- “parking was hard”, “주차가 조금 불편”, “조금 멀다”

### 2

- “parking nightmare”, “주차 지옥”, “위치가 너무 외진 곳이라 오기 힘들다”

---

## 3. Binary Tags (0/1)

연속 점수가 아닌, **존재 여부만 판단**하는 특수 태그.

---

### 3.1 RACISM FLAG → `racism_flag`

**인종/민족/국적/외모/언어** 관련 차별 또는 혐오 표현이 있을 때만 1.

### 1 (True)

- “racist staff”, “treated differently because we are Asian”
- 인종/국적/외모/언어를 이유로 한 차별적 언행

### 0 (False)

- 일반적인 무례, 폭력, 시비, 싸움 등
→ 차별 의도가 명시되지 않은 경우는 0
(예: “술 취한 사람이 와서 시비 걸었다” → racism 아님)

---

### 3.2 CASH ONLY FLAG → `cash_only_flag`

여행자에게 매우 중요한 **결제 수단 제한** 요소.

### 1 (True)

- “cash only”, “no cards”, “현금만 받음”, “카드 안 받음”

### 0 (False)

- 일반적인 결제 언급 혹은 언급 없음

---

## 4. 언급이 여러 개일 때의 처리 원칙

### 4.1 동일 Aspect 내 긍정/부정 혼재

하나의 리뷰 안에서 **같은 Aspect에 대해 긍정과 부정이 함께 언급**될 수 있다.

이 경우 감정을 평균내지 않고, 가장 강한 감정(절대값이 큰 쪽)을 기준으로 점수를 결정한다.

**원칙:**

- 최고 부정(-2) 표현이 포함된 경우 → 최종 점수 = **2**
- 2는 없지만 부정(-1) 표현이 포함된 경우 → 최종 점수 = **1**
- 부정 표현이 없고, 강한 긍정(+2)이 포함된 경우 → 최종 점수 = **+2**
- 그 외 일반적인 긍정 표현만 있으면 → **+1**

**예시:**

- “맛은 좋았지만 너무 짜서 토할 것 같았다.”
→ 긍정(맛 좋음) + 매우 부정(토할 것 같았다) 섞임
→ `food_score = -2`
- “서비스는 좋았지만 너무 느렸다.”
→ `service_score = -1` (불만이 더 핵심 메시지)

---

### 4.2 0점(중립/언급 없음) 확정 규칙

다음의 경우 해당 Aspect는 **0점**으로 확정한다.

1. 해당 Aspect에 대한 **언급이 전혀 없는 경우**
2. “괜찮았다”, “그냥 그랬다”, “so-so” 등 **명확한 호불호가 없는 중립적 표현**
3. “음식은 괜찮았으나, 가격이 너무 비싸다” 처럼
앞부분의 긍정이 **뒤 Aspect(가격 등)의 부정을 위한 도입부**에 불과한 경우:
    - 이때 `food_score`는 0(또는 +1까지도 가능하지만, 기준 단순화를 위해 0으로 기본 처리)
    - 핵심 불만은 price에 반영 (`price_score = -1 또는 -2`)
